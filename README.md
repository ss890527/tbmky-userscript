# TBM-KY 上傳小助手

[安裝／更新腳本](https://raw.githubusercontent.com/ss890527/tbmky-userscript/main/tbmky.user.js)

使用已安裝 Tampermonkey 的瀏覽器開啟連結。固定網址提供已發布版本；後續更新保留同一網站本機儲存的常用包與危害設定。更新後重新整理網站。

## 首次設定

完成網站登入並進入 TBM-KY 資料上傳頁；先不要選附件。手動選擇網站的「承攬商」，等工作選單載入，展開助手「⚙ 本機勞務包設定」，點「從網站讀取勞務包」，勾選本機常用包並儲存。不用手打包名或內部網址，各電腦可以設定不同工作。

## 使用

核對本次日期、包名、概要與危害後，助手填寫表單並帶出宣導。登入、三張 JPG 選檔、核對宣導及最後「開始上傳」保留人工操作。網站改名或移除工作時停止，不猜替代項；重新從網站選單設定。重複名稱改用人工流程。

## 更新與資料

啟用 Tampermonkey 更新檢查，依本機檢查週期更新；也可點上方連結手動更新。常用包與各包危害存於目前網站的 localStorage，未完成進度存於 sessionStorage；不傳至 GitHub，也不跨電腦同步。清除網站資料後需要重新設定。

公開程式不含內部網站位址、固定勞務包名稱、登入資料或附件。腳本僅匹配 `/TBMKY/*.aspx`，且只在首頁與資料上傳頁建立助手；不會自己送出最終上傳。

v1.2.0：語法與 28 組離線情境通過。離線模型不能替代真實網站、Tampermonkey 安裝與完整上傳驗證。
