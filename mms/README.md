# MMS工作日誌小助手

版本：0.1.5

[安裝／更新腳本](https://raw.githubusercontent.com/ss890527/tbmky-userscript/main/mms/mms.user.js)

自行登入工作日誌網站。人員直接可見，首次按「讀取人員」並勾選；主操作只有「填寫」，設定自動記住。「其他設定」已移除，一般工作固定 8 小時。

現場接受 LINE 工項，本業合計 8，TBM-KY 固定 1。補項只從最後新增，重分配本人工項，含會議超過 8 項用 0.5 小時單位，保留其他人員工項及原序號。

非現場可手輸或選常用項目，只有明確加入才變成常用；一般主項 8／100%。下午請假預設請 4，主項與人員工作 4 小時、0800–1200；請 3 則工作 5 小時、0800–1330。填上午工作內容，不加會議。全天「請假」仍工項 8／100%，人員時間及工時為 0。

假日加班不分單位，手輸一項工作，預設 8，可改 9～12；工作時間分別為 0800–1800／1900／2000／2100。

週一至五一般現場／非現場可勾選平日加班 2／3／4 小時，預設無，內容預設「大修工作」可改。本業 8 與加班分列，總工時 10／11／12，時間 0800–1900／2000／2100。休息不計工時；按指定規則每滿 4 工時休息 30 分鐘，下班邊界不另加休息。下午請假、假日及全天請假不疊加平日加班。

本人已填的主項或加班沿用可調整項；需改到未勾選者共用項目時另加新列。非現場／假日只指派本次主項與適用加班，取消加班解除本人指派，原共用日誌列保留。

填寫後請親自核對及點「存檔」，程式不自動存檔或簽核。人員、類型、請假／加班參數及上次手輸內容保存於目前網站本機瀏覽器，更新沿用原儲存鍵；舊任意目標改成固定 8，保留人員及常用選項。跨頁草稿最多 10 分鐘。

已完成匿名化離線測試，內網、初次安裝及篡改猴實際自動更新仍待使用環境驗證。
