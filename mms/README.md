# MMS工作日誌小助手

版本：0.1.3

[安裝／更新腳本](https://raw.githubusercontent.com/ss890527/tbmky-userscript/main/mms/mms.user.js)

自行登入工作日誌網站。填寫人員直接顯示於面板上方，首次按「讀取人員」並勾選；人員、時數及填寫類型一律自動保存上次設定，不需記憶開關或保存按鈕。主操作只有「填寫」，沒有預覽與停止，需修改時直接調整網站表單。

現場模式接受 LINE 請修訊息，加入 TBM-KY 並分配時數。非現場每次填一項 8 小時、100%；既有日誌可有其他人員多項，所選姓名未填過時從最後新增本次工項並指派新序號，不扣其他工項時數。可直接手輸特殊項目或選常用再編輯，只有按「加入常用項目」才加入清單；記住上次文字不會自動加入常用；選「請假」時所選人員的工作時間與總時數均填 0。

助手先核對工作日期與部門，填寫後請親自核對並存檔。程式不自動存檔或簽核。異常或既有內容不符時停止，已填內容保留。

人員設定與非現場常用項目分別存於目前網站的本機瀏覽器。更新不清空設定；跨頁草稿保留最多 10 分鐘。使用 Tampermonkey 原生更新檢查，更新後請重新整理頁面。

已完成匿名化離線測試，內網、初次安裝及實際自動更新仍需在使用環境驗證。
