# 行動簽核小幫手

版本：0.1.0

[安裝／更新腳本](https://raw.githubusercontent.com/ss890527/tbmky-userscript/main/sign/sign.user.js)

台電 EI 行動假單（LTRWD）與行動加班（PARWD）的簽核輔助，需先安裝篡改猴（Tampermonkey）。自行登入，腳本不填驗證碼、不按登入。

- 簽核代理（假單）與出勤簽核（加班）：待簽項目的下拉自動從「不處理」改成「同意」；已有其他選擇不覆蓋。「確認送出」只加橘框，由使用者核對後自行按，送出後的 OK 也由使用者按。
- 請假頁：進入時的單一 OK 提示自動關閉；代理人第一次手選，之後自動帶入（只記在自己的瀏覽器，不上傳）。
- 登入後首頁會跳往簽核頁（加班要待簽數大於 0），同一分頁只跳一次。

已完成模擬頁面的離線測試；公司內網與篡改猴實際更新仍待使用環境驗證。
